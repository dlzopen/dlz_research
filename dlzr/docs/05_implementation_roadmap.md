| 编号 | 交付物 | 验收标准 | 预估工期 |
|------|--------|----------|----------|

### 里程碑验证
- [ ] `cmake --build` 在 Windows (MSVC) 和 Web (Emscripten) 上零错误编译

- [ ] ANM 动画帧序列正确播放（以 FFPACT00.ANM 为测试素材）
- [ ] CI 每次 push 自动构建并报告结果

### 技术要点

```
IMG 格式:
  - 16 字节头: width(2), height(2), palette_offset(2), ...
  - 8-bit 调色板索引像素数据
  - 调色板: 256 × 3 bytes (RGB)

ANM 格式:
  - LPF 头 + ANIM 头
  - 4 种 RLE 操作码:
    OP_COPY  (0): 直接复制 n 字节
    OP_SKIP  (1): 跳过 n 字节（透明）
    OP_DELTA (2): 对前帧 n 字节加偏移
    OP_FILL  (3): 填充 n 字节为同一值
  - Delta 编码: 基于前帧差异
```

## 关键路径分析

```
关键路径: Phase 0 → Phase 1(战斗核心) → Phase 2(战略层) → Phase 3(全流程) → Phase 4(多端)

最长子路径:
  Phase 1: 攻防公式(4d) → 技能系统(3d) → 回合调度(3d) → AI行为(3d) → 胜负判定(2d)
  = 15 天（3 周）

可并行工作:
  - Phase 0 期间: IMG加载器 与 ANM加载器 可并行
  - Phase 1 期间: 公式单元测试 与 战斗渲染 可并行
  - Phase 2 期间: 存档系统 与 转职系统 可并行
  - Phase 3 期间: 对话系统 与 音频系统 可并行
```
