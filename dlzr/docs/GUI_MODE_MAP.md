# GUI 界面与切换逻辑完整逆向

> 基于 DLZ.exe 逆向代码的完整 GUI 分析
> Dispatcher: FUN_00425340 @ 0x00425340, switch on DAT_007db4e8

## 架构概览

```
WndProc @ 0x425641
  └─ InputDispatcher @ 0x425340 (DAT_007db4e8 = game_mode)
       ├─ 标题画面 (modes 0-3)
       ├─ 角色选择 (mode 4)
       ├─ 过渡/结算 (modes 5-7)
       ├─ 城镇菜单 (modes 50-58)
       ├─ 战略地图 (mode 150)
       └─ 过渡/元模式 (modes 100, 120, 250, 999)
```

关键全局变量:
- `DAT_007db4e8` — 主游戏模式状态
- `DAT_007d0cf0` — 前一模式/子模式追踪
- `DAT_007d0cf4` — 帧计数器（动画用）
- `DAT_00584358` — 选择索引（上下文相关）

事件类型:
- `0x100` — WM_KEYDOWN / 初始化渲染
- `0x113` — WM_TIMER / 定时动画
- `0x200` — WM_MOUSEMOVE / 鼠标悬停
- `0x201` — WM_LBUTTONDOWN / 鼠标按下
- `0x202` — WM_LBUTTONUP / 鼠标释放

## 标题画面 (Modes 0-3)

### Mode 0 — 标题动画 FUN_0042c3a5 (635B)
- 播放 kr_1.flc 开场动画
- 初始化: `FUN_0043e190(local_88, "kr_1.flc")`, `FUN_004262b6(local_88, 1)`
- 动画结束后: `DAT_007d0cf0=0, DAT_007db4e8=1` → Mode 1
- 鼠标点击 (0x202): 跳过动画直接进入 Mode 1

### Mode 1 — 标题菜单 FUN_0042c7d4 (2070B)
背景: MINE01.IMG (640×480)

**5个菜单按钮:**
| 按钮 | 文字 | 位置 | 大小 | 目标模式 |
|------|------|------|------|----------|
| 0 | 初出茅庐 | (315, 60) | 232×56 | Mode 4 (角色选择) |
| 1 | 继往开来 | (315, 132) | 232×56 | Mode 5 (继续游戏) |
| 2 | 战斗英雄 | (315, 204) | 232×56 | Mode 2 (排行榜?) |
| 3 | 支前模范 | (315, 270) | 232×56 | Mode 6 (排行榜?) |
| 4 | 部队休整 | (315, 336) | 232×56 | Mode 3 (休整?) |

按钮图片: DAT_0058c3a8/0058f668/00592928/00595be8/00598ea8 (各 232×56)

**动画高亮:**
- 位置: x=250, y=选中按钮Y, 56×48
- 30帧动画, 每帧 2688 bytes
- 来源: DAT_005d73a8 + (frame % 30) * 0xa80

**切换逻辑:**
```
所有按钮点击:
  FUN_0043c954(5)                    // 播放音效5
  DAT_007d0cf0 = 1                   // 标记来源=标题
  DAT_007db4e8 = 目标模式
  FUN_00425ad4(&DAT_0096a790, 1, DAT_007d01c4)  // init fighters
  FUN_0043c2dd()                     // finalize
```

### Mode 2 —  dismiss/返回 FUN_0042d1c6 (81B)
- 任意键/点击 → 返回 Mode 1
- `DAT_007d0cf0=2, DAT_007db4e8=1`

### Mode 3 — 自动对话 FUN_0042d274 (247B)
- WM_TIMER: 10帧后显示 320×200 对话框
  - 对话框返回0: `init_battle_fighters(mode=4)`, PostMessage(WM_KEYDOWN)
  - 对话框返回非0: 返回 Mode 1
- `DAT_007d0cf0=3, DAT_007db4e8=1`

## 角色选择 (Mode 4)

### Mode 4 — 角色选择 FUN_0042e2d6 (5223B) ***最大界面***
背景: MENU01.IMG (640×480)

**布局:**
```
┌─────────────────────────────────────────────┐
│  [头像0] [头像1] [头像2] [头像3] [头像4] [头像5] │  y=86
│   80×100  each, x=40,136,232,328,424,520    │
│                                             │
│         [阵型0][阵型1][阵型2][阵型3]          │  y=203
│          48×48, x=163,251,339,427           │
│                                             │
│    攻击力 ◄═══════●═══════► 防御力           │  y=287
│    (255,287) 128×16 slider                  │
│                                             │
│    [简单] [普通] [困难]                       │  y=371
│    (249,371) 344×22                         │
│                                             │
│     [更改]    [确定]    [取消]                │  y=425
│   (138,425) (275,426) (412,427) 88×32       │
└─────────────────────────────────────────────┘
```

**头像数据:**
- 初始显示: FACE.DAT offset 0xC92C0 = 103*8000, 6张 (indices 103-108)
- 确认后加载: 40张 (0x28), 使用索引表 `DAT_007d0f08 + i * 0x84`
- 每张 8000 bytes (80×100, 8-bit indexed)

**按钮图片:** BUTTON22.IMG, offset 0x10, 5632 bytes (2 states per button)

**切换逻辑:**
```
更改按钮 (0x8a, 0x1a9, 0x58, 0x20):
  → DAT_00584358 = 0, 重绘按钮

确定按钮 (0x113, 0x1aa, 0x58, 0x20):
  → 进入战斗准备:
    DAT_007d0cf0 = 4
    FUN_0043c76b()                    // 初始化
    DAT_007d0f08 = DAT_0098d7f4 + 0x67  // 起始头像索引
    加载40张头像 (loop 0x28次)
    设置阵型参数:
      type 1 → DAT_007d0f6e = 100
      type 4 → DAT_007d0f6e = 82
      type 8 → DAT_007d0f6e = 109
    DAT_007d0f14 = 攻击力 (DAT_0098d800)
    DAT_007d0f18 = 防御力 (0xa0 - DAT_0098d800)
    复制16个阵型加成
    FUN_00416c70() / FUN_00416e3c()   // 战斗初始化
    FUN_004292fe()                    // 关卡初始化
    DAT_007db4e8 = 0x96 (150)        // → 战略地图/战斗

取消按钮 (0x19c, 0x1ab, 0x58, 0x20):
  → DAT_007d0cf0 = 4
  → DAT_007db4e8 = 4 (重新进入角色选择)
  → 实际效果: 返回标题 Mode 1
```

## 过渡/结算 (Modes 5-7)

### Mode 5 — 过渡/结算 FUN_004300e1 (370B)
- WM_TIMER: 10帧后调用 `FUN_004282f9(1)` 获取结果
  - 结果 0-4: 显示奖励 `FUN_00427fef(result)`, 进入 Mode 150 或 Mode 57
  - 结果 <0 或 >5: 返回 Mode 1
- 特殊: Mode 0x39 时关闭句柄

### Mode 6 — 胜利动画 FUN_004303b8 (293B)
- WM_TIMER: 滚动图片, 每帧 0x500 bytes
  - 来源: ZBY.IMG, offset = frame * 0x500 + 0x4b010
  - 最大帧数: 0xdd4 (3540)
  - 渲染: 640×478, 双缓冲
- 点击/按键 → 返回 Mode 1

### Mode 7 — 关卡选择 FUN_0042faca (1466B)
**关卡选择 + 密码输入界面:**

UI元素:
- 上/下翻页: (320,16,64,16) / (400,16,64,16)
- 开始(有密码): (480,16,64,16) → Mode 4
- 删除字符: (160,16,64,16)
- 开始(无密码): (240,16,64,16) → Mode 4
- 关卡列表: (0,48,613,24) — 23个分类
- 关卡网格: (0,72,640,408) — 20×13格

密码系统:
- 8字符缓冲区: DAT_0098d760
- 光标闪烁: 13帧周期
- 字符编码: char1 = level/94 - 80, char2 = level%94 - 95

## 完整游戏流程

```
Mode 999 (重置) → Mode 0 (标题动画)
  → Mode 1 (标题菜单)
    ├─ 初出茅庐 → Mode 4 (角色选择)
    │   ├─ 确定 → Mode 150 (战略地图/战斗)
    │   ├─ 取消 → Mode 1
    │   └─ 更改 → Mode 4 (重入)
    ├─ 继往开来 → Mode 5 (继续游戏)
    ├─ 战斗英雄 → Mode 2 (排行榜)
    ├─ 支前模范 → Mode 6 (排行榜)
    └─ 部队休整 → Mode 3 (休整)

Mode 150 (战略地图)
  ├─ 战斗胜利 → Mode 5 (结算) → Mode 1 (返回标题?)
  ├─ 进入城镇 → Mode 120 → Mode 50 (城镇菜单)
  │   ├─ 军队信息 → Mode 51 → Mode 50
  │   ├─ 物资装备 → Mode 52 → Mode 50
  │   ├─ 招募 → Mode 53/56 → Mode 50
  │   ├─ 锻造 → Mode 54 → Mode 50
  │   ├─ 存档/读档 → Mode 55 → Mode 50
  │   ├─ 布雷 → Mode 57 → Mode 50
  │   └─ 确认 → Mode 58 → Mode 50
  └─ 下一关 → Mode 100 → Mode 150

Mode 7 (关卡选择)
  └─ 开始 → Mode 4 (角色选择)
```
